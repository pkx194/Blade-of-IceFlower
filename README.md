# Blade-of-IceFlower · 冰花之刃

Minecraft **1.20.1 / Forge 47.x** 的拔刀剑附属，单人自用。当前版本 **v0.1（预览）**：功能齐了，
但还在观察期，配方的门槛与必杀技的手感后面都可能调。Mod 列表里显示为 **Blade of IceFlower**；
整个 mod 带一把成品命名刀 `hyoubana:ice_flower`（冰花之刃）、一把只为合成链存在的过渡刀 `hyoubana:ice_heart`（冰芯），
外加一位刀灵「冰魄」。它是一整套**招式演示**：五记必杀技各有各的节奏，卖的东西互不重叠。

> 名字说明：仓库、jar 与 Mod 列表显示名都叫 **Blade of IceFlower**，但 mod 的**内部 id 仍是 `hyoubana`**——
> 它写进了 `hyoubana:ice_flower` 这类命名空间、语言键和已有存档，改不得。所以下面凡是带 `hyoubana:` 的
> 都是技术 id，不是旧名残留。中文名「冰花之刃」不变。

## 运行环境

- Minecraft **1.20.1**，Forge **47.x**（47.4.16 编译，47.3.12 实测可加载）
- **前置：拔刀剑·重锋（SlashBlade Resharped）`slashblade` 1.9 及以上**，`mods.toml` 里是 mandatory、`ordering=AFTER`
- 本附属**不注册任何物品**：成型刀的物品 id 永远是 `slashblade:slashblade`，刀与刀的区别只在刀的定义数据
- 单人游戏放一份 `mods/` 就够；局域网联机时每位加入者的客户端也要装同一份（注册了实体、必杀技与连段状态）

## 拿到这把刀

生存里可以合成，但要分两趟，走的是本体那套命名刀配方（`slashblade:shaped_blade`）。

**第一趟：养成一把「冰芯」**（`hyoubana:ice_heart`）。中间摆一把已经是妖刀的本体刀，四角四棱铺八份耀魂供品：

| 位置 | 放什么 |
| --- | --- |
| 中心 | 本体刀（`slashblade:slashblade`），要已经是 `bewitched` 妖刀，且耀魂 ≥ 5000、精炼 ≥ 10 |
| 四角 | 耀魂结晶 ×4 |
| 四棱 | 耀魂宝珠 ×4 |

冰芯是过渡刀：能用、有妖刀身份，但没有冰花之刃的五记必杀技，也没有刀灵。它自己不会掉，合成出来就得往死里用。

**第二趟：冰芯养成冰花之刃**（`hyoubana:ice_flower`）。中间换成刚那把冰芯，而且这次要的是**它砍出来的战绩**：

| 位置 | 放什么 |
| --- | --- |
| 中心 | 冰芯，要耀魂 ≥ 8000、精炼 ≥ 16、**斩录 ≥ 256** |
| 四角 | 蓝冰 ×4 |
| 四棱 | 耀偏方三八面魂（最高档耀魂供品）×4 |

斩录这一项没法用钱买：合成台认的是这把刀自己攒下的击杀数，而每次合成都会把斩录与耀魂清零重来，
所以冰芯必须在手里真砍够 256 只。门槛比本体自己的顶级命名刀（村正：耀魂 10000 / 精炼 20 + 八颗宝珠）高一截——
这把刀带五记必杀技和一位刀灵，合成上就该是这么一件麻烦事。

创造模式的拔刀剑标签页里有成型刀。想单独把某一记装到别的刀上，走本体的耀魂宝珠：

```
/give @s slashblade:proudsoul_sphere{SpecialAttackType:"hyoubana:myriad_swords_return"}
```

## 面板

`attack_base 10` / `max_damage 100` / `sword_type: bewitched`
锋利 V、亡灵杀手 V、节肢杀手 V、抢夺 V、耐久 V、**力量 V**（最后那一条是本体幻影剑的伤害槽，不给的话中键那排剑打不出数字）。
刀身模型是本附属自带的 OBJ。

## 五记必杀技

| 必杀技 | 键 | 妖力 | 卖什么 |
| --- | --- | --- | --- |
| 真\*次元斩 | `hyoubana:true_judgement_cut` | 30 | 「切开了却没断」。落刀在正前方铺开一片天蓝刀痕，罩住的活物当场静止；刀痕画出白→蓝→深蓝渐变的发光裂缝；收刀那一拍所有刀痕同时爆成亮天蓝（数层斩击 + 彩色落雷 + 大爆炸），之后冲击波推出去 |
| 魔次元斩 | `hyoubana:magic_dimension_cut` | 36 | 一记**不停时间**的次元斩，卖节奏：落刀划开二十几道细线散在外圈，十几拍后按各自相位依次崩断，白光洗屏一次 |
| 极·鬼剑术 | `hyoubana:extreme_ghost_swordsmanship` | 40 | 「人进了阵」。二十四把剑依次钉成一圈，两秒内阵里一把一把轮流斩；收刀时全部收拢阵心一次性结算 |
| 万剑归宗 | `hyoubana:myriad_swords_return` | 60 | 「天上下剑」。穹顶在头顶成形，四十八把剑按各自先后落下、一圈圈往外扩；攒满后一起穿进球心、穿完凭空抹掉，只留向外推的冲击波 |
| 魔狱血刹 | `hyoubana:demonic_blood_slam` | 48 | 唯一一记烫的。抽自己的血凝成一把七格长巨刃绕弧砸下，落地翻起整片地皮，加滞留两秒多的血池。起手先扣施术者两格血，但永远不会把自己打死 |

超级档按本体的通道走：按住特殊移动键（默认 V）攒满 20 拍释放。每记都显式给了短蓄力与超级档两个落点。

## 冰魄（刀灵）

`hyoubana:ice_spirit`——一把会自己飞、自己砍、自己放幻影剑的悬空冰刃，不穿人形。

- **出场**：手上这把是冰花之刃、杀够 **20** 只、且这个世界还没有她的冰魄，就把她叫出来；UUID 随存档走，
  切维度与下线各自退场
- **站得住**：血量 100、抗性提升 IV、击退抵抗满、每半秒按上限比例回血
- **不打自家**：本附属自己的必杀技不会把她扫掉；招式与敌人判定走本体的连段状态机

## 中键幻影剑

彩虹七色：每把剑出生时领一种颜色，命中那一拍**按颜色发不同的效果**。只改这把刀的幻影剑，
整合包里其它拔刀剑的配色与手感一律不动。

## 伤害口径

能走本体的伤害就走本体，只把**没砍到的差额**补到直接写读数那一层。补的那一下不走管线，所以没有受击闪光、
不进连击计数、也不结算掉落——它是「额外附加的一层」，不是主伤害。

## 已知限制与风险（务必读）

- **仅单人 / 局域网房主**。别装到公开服务端。
- 它只改自己这把刀的必杀技、幻影剑与召唤物，不碰别人的实体状态。
- 猛锋门槛（超级档要杀敌数达标）写不进本体的刀定义文件，只能运行时补。
